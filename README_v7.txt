Daily Study v7 — Sol 품질 유지 + 비용 가드 + 향후 법과목 전환 준비

현재 동작
- 모델: gpt-5.6-sol
- reasoning effort: high 유지
- 현재 과목: TOEIC Part 6 4문항 + Part 7 2문항 + 민법 1 + 물리 1 + 화학 1 + 생물 1
- 난도 기준은 v6 그대로: TOEIC 실전 지문, 민법 변리사 1차 기출급, 자연과학 대학 일반과학 + 변리사 기출급

비용 가드
1) 새 Day당 OpenAI 자동 호출은 1회만 허용합니다.
   - v6처럼 품질검사 실패 시 자동으로 한 번 더 호출하지 않습니다.
   - 정말 실패한 경우에만 화면의 재시도 버튼으로 사용자가 직접 다시 시도합니다.
2) 한 번 만들어진 Day는 영구 캐시합니다.
   - 새로고침, PC→폰 이동, 다음날 접속으로 재생성하지 않습니다.
   - 코드/프롬프트 버전이 바뀌어도 이미 생성된 Day는 자동 재생성하지 않고 다음 Day부터 새 버전을 적용합니다.
3) 민법 참고자료 전체를 매번 보내지 않습니다.
   - 최근 오답/헷갈림/복습 개념과 관련된 부분을 우선 선별하여 최대 약 14,000자만 모델에 전달합니다.
4) 최근 복습/정오답 컨텍스트도 필요한 범위로 줄였습니다.
5) max_output_tokens를 8,500으로 제한했습니다.
   - Sol High reasoning은 그대로 유지하면서 한 번의 생성이 과도한 토큰을 사용하지 않도록 제한합니다.

비용 목표
- 하루 한 번 새 Day를 생성하는 정상 사용을 전제로 월 1만원 안쪽을 목표로 한 설정입니다.
- 환율/세금, 수동 재시도 횟수, 실제 입력 토큰량에 따라 절대적인 상한을 보장하는 것은 아닙니다.
- 같은 Day를 다시 접속하는 것은 OpenAI API를 다시 호출하지 않으므로 추가 생성비용이 없습니다.

설치/업데이트
1) ZIP의 api/generate-day.js를 GitHub daily-study/api/generate-day.js와 교체
2) Commit
3) Vercel 자동 재배포 대기
4) 추가 SQL은 필요 없음
5) 현재는 STUDY_TRACK 환경변수를 만들지 않아도 됩니다. 기본값 current입니다.

향후 TOEIC 제거 + 특허/상표/디자인법 추가
- 코드에 patent_focus 트랙을 미리 넣어 두었습니다.
- 나중에 UI의 법과목 참고자료 입력 기능까지 추가한 뒤 Vercel Environment Variable에
  STUDY_TRACK = patent_focus
  를 설정하면 생성 구성은 아래처럼 전환할 수 있습니다.
  민법 1 + 특허법 1 + 상표법 1 + 디자인보호법 1 + 물리 1 + 화학 1 + 생물 1
- 특허/상표/디자인법도 단순 조문 암기가 아니라 변리사 1차 기출급 5지선다로 생성하도록 기본 출제 규칙이 포함돼 있습니다.
- 실제 전환 시에는 사이트의 '민법 자료' 메뉴를 '법과목 자료'로 확장해서 과목별 자료를 추가할 수 있게 한 번 더 업데이트하는 것이 좋습니다.
